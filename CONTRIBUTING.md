# CONTRIBUTING

Thanks for contributing to ABEHA.

## How to Contribute
1. Create or pick a GitHub Issue.
2. Create a focused feature/fix branch.
3. Keep changes small and module-scoped.
4. Add/update tests where applicable.
5. Submit a PR with clear summary and validation notes.

## Contribution Guidelines
- Follow `DEVELOPMENT_RULES.md`.
- Do not introduce out-of-scope integrations.
- Use synthetic data only.
- Avoid committing secrets or environment files.

## Review Checklist
- Scope is focused
- Security constraints respected
- Tests and docs updated as needed
- No unrelated refactors
